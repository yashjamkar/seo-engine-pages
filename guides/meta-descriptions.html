Meta descriptions and search snippets

The text under a result's link is called the snippet. A meta description is your suggestion for it; search engines treat it as a suggestion, not an instruction.

When your description is used

Google often shows the meta description when it summarises the page well for the search that was typed. For other searches it may pick a passage from the page that matches the query better, so one page can show different snippets for different searches.

Length

There is no fixed limit; snippets are cut to fit the space available, which differs between phones and computers. Put the most useful information first so a shortened snippet still makes sense.

What helps

  • Describe this page, not the whole site.
  • Include concrete facts a searcher cares about: prices, sizes, opening hours, what the guide covers.
  • Write a different description for each page.
  • Avoid claims the page does not support; the click is wasted if the page disappoints.

What a description does not do

A description influences whether people click a result. It is not used to decide where the page ranks, so a better description shows up as a higher click-through rate at the same position, not as a better position.
